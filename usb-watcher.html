Overview

USB-DLP Watcher Agent is a real-time Data Loss Prevention tool for Linux that monitors file transfers written to external USB storage. It detects policy violations as they happen, keeps a tamper-evident audit trail of every transfer, and gives administrators a dedicated console to manage rules and review activity.

Key Features

  • Real-Time, In-Flight Detection: Policy violations are caught the instant they occur — including interrupting an oversized or prohibited transfer while it's still in progress, not only after it completes.
  • Boot-Independent Coverage: Protection is active from the moment the system starts, independent of whether any user is logged in or a desktop session is running.
  • Multi-Layered Detection Rules: Violations are flagged across five independent layers — file type, filename or path pattern, size thresholds, cryptographic file fingerprinting, and in-document keyword content across common file formats.
  • Cryptographically Chained Audit Log: Every recorded event is mathematically linked to the one before it. Any alteration of historical records — even a single entry — breaks the chain and is detectable with a single on-demand integrity check.
  • Zero Standing Privilege: Hardened by design, no administrative session is ever cached. Every policy change independently re-authenticates against the operating system itself, every single time — there is no window of elevated access to exploit.
  • Cumulative Alerting: Desktop notifications surface meaningful patterns of activity based on administrator- defined thresholds, rather than triggering on every isolated event.
  • Dedicated Management Console: A native Linux desktop application for system overview, rule management, filterable and exportable audit history, and live diagnostics — including on-demand log integrity verification.
