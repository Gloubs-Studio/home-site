Tech Stack

Technologies and frameworks powering our applications, mobile projects, extensions, and workflow automation.

Languages & Core Technologies

  • Python: Main application development, automation, and tooling.
  • JavaScript (ES6+): Front-end controls and lightweight web components.
  • HTML5 / CSS3: Responsive layout architecture using custom CSS properties.

Application & Mobile Development

  • Kivy: Cross-platform Python framework for building mobile and desktop applications.
  • PySide6 (Qt6): Cross-desktop native GUI framework for security and monitoring tools.
  • Tkinter: Built-in Python library for rapid desktop GUI prototyping and utility tools.
  • MIT App Inventor: Visual development platform used for mobile prototyping.

Security & Data Infrastructure

  • SQLite: Local data logging with tamper-evident, cryptographically-chained audit trails.

Extensions & Automation

  • LibreOffice API / PyUNO: Direct integration layers for document processing, automation, and privacy analysis.
  • PyInstaller: Executable compilation and standalone application packaging.

Imaging & Asset Management

  • Pillow (PIL): Image manipulation, image processing, and visual media handling.
